# Support

## Questions and problems

Ask a question or report a problem as an
[issue on GitHub](https://github.com/nimblescape/markdownpaper-vscode/issues).
Search the existing issues first. When an issue describes your problem
already, add your information to that issue.

A report helps most when it contains:

- the version of the extension and the version of VS Code ("Help", "About"),
  or the version of the command (`markdownpaper --version`);
- your operating system, and the browser that prints the PDF (Google Chrome,
  Chromium or Microsoft Edge) with its version;
- the shortest Markdown text that shows the problem, in a code block, and the
  files of the layout when the layout is part of the problem;
- where the problem shows: in the page preview, in the PDF, in the warnings of
  the text editor or on the command line;
- what you expected, and what you see instead, for example a screenshot of a
  page or the error message.

The
[user guide](https://github.com/nimblescape/markdownpaper-vscode/blob/main/docs/guide.md)
describes every feature and its limits.

## Security problems

Do not report a security problem in a public issue. Write an e-mail to
scalarion@nimblescape.com instead.
